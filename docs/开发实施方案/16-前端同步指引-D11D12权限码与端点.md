# 16-前端同步指引 — D11/D12 权限码与端点变更（OmniAdmin 仓库）

> **创建日期：** 2026-08-12
> **关联：** `docs/开发实施方案/16-菜单权限单表化-SharpFort模型-决策与实施清单.md`（v1.5，D11/D12）
> **适用仓库：** OmniAdmin（main 分支）
> **变更性质：** 后端 055 已实施并推送（commit `505c962`）；本指引为前端唯一需要同步的增量（D11 权限码前缀 + D12 端点语义）

## 1. 变更背景（前端只需知道三件事）

| # | 变更 | 前端影响 |
|---|---|---|
| D11 | 权限码命名空间 **`sys:` → `public:`**（后端已全部收敛：iam_menu.api_code、has_permission 判定键均为 public:） | 前端**硬编码的 'sys:' 权限码字符串**必须同步改 'public:'，否则 v-perm 判定永不命中 → 按钮全隐藏 |
| D12 | 菜单按钮行 api_url 改为**真实端点**（占位路径 `/rpc/sys:*` 不再使用；如 public:user:list → POST /rpc/search_users） | 菜单表单端点输入示例更新；数据自动（后端驱动），前端无逻辑改动 |
| — | 权限码集合**数据驱动**：usePermission 从 `v_role_menu_detail.permission_code` 拉取（055 已改），后端返回即 public: 码 | **无需改代码**——只要硬编码字符串同步即可 |

## 2. 必须修改：12 处硬编码 `'sys:` 权限码 → `'public:`（10 个文件）

> 替换规则：`v-perm="'sys:xxx:yyy'"` → `v-perm="'public:xxx:yyy'"`（含注释示例）。
> 后端已收敛为 public:，**此处是唯一的前端硬编码点**；漏改一处 = 该按钮永久隐藏。

|---|---|---|---|---|
| 1 | `src/directives/core/perm.ts` | 9（注释示例） | `'sys:dept:create'` | `'public:dept:create'` |
| 2 | `src/hooks/core/usePermission.ts` | 109（注释示例） | `'sys:dept:create'` | `'public:dept:create'` |
| 3 | `src/views/system/dept/index.vue` | 7 | `v-perm="'sys:dept:create'"` | `v-perm="'public:dept:create'"` |
| 4 | `src/views/system/dict/index.vue` | 12 | `v-perm="'sys:dict:create'"` | `v-perm="'public:dict:create'"` |

**一键替换命令（git-bash / Linux）：**

```bash
cd <OmniAdmin>
# 仅替换权限码字面量（'sys: → 'public:），不碰其他 sys 文本
grep -rl "'sys:" src/ | xargs sed -i "s/'sys:/'public:/g"
# 复核：应只剩 0 处
grep -rn "'sys:" src/ | grep -v node_modules || echo "OK: 无残留"
```

**替换后验证：**
1. `pnpm build`（vue-tsc + vite）全绿
2. 运行时验证（需后端 055 已部署）：
   - 用 tenant_admin 登录 → 部门/字典/岗位页的"新增"按钮**可见**（权限码 public:dept:create 命中）
   - 用普通角色登录 → 无绑定按钮仍隐藏（未绑拒绝）
   - 超管登录 → 全按钮可见（超管短路）
