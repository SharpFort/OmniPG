## 六、快速启动

```bash
# 1. 确保 WSL2 基础设施已启动
wsl -d Ubuntu-26.04 -- systemctl start postgresql@18-main pgbouncer etcd redis-server grafana-server

# 2. 设置端口转发（Windows PowerShell，管理员）
# 或运行: powershell -ExecutionPolicy Bypass -File scripts/wsl-portproxy.ps1
netsh interface portproxy add v4tov4 listenport=6432 listenaddress=0.0.0.0 connectport=6432 connectaddress=<WSL2_IP>
netsh interface portproxy add v4tov4 listenport=5432 listenaddress=0.0.0.0 connectport=5432 connectaddress=<WSL2_IP>

# 3. 启动 Docker 网关栈
cd gateway && docker compose up -d

# 4. 初始化 APISIX 路由（仅首次或路由清空后）
bash scripts/init-apisix-routes.sh

# 5. 全栈验证
bash scripts/verify-stack.sh
```

## 七、验证命令

```bash
# PostgREST
curl -s http://localhost:3001/ | wc -c          # >2000 字符

# APISIX 就绪
curl -sf http://localhost:7085/status            # {"status":"ok"}

# Casdoor 健康
curl -sf http://localhost:8000/api/health        # {"status":"ok"}

# Swagger UI
curl -sf http://localhost:8082/                  # 200

# Pigsty WebUI
curl -sf http://localhost:8080/                  # 200

# Grafana 代理
curl -sI http://localhost:8080/ui/d/pgsql-overview  # 302
```
