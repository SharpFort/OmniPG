# OmniPG 服务访问速查手册

> **环境**: Windows 10 + WSL2 Ubuntu 26.04 + Docker Desktop + Pigsty v4.4.0
> **更新**: 2026-09-05 | **分支**: refactor/schema-platform-logto-public（IAM 已由 Casdoor 迁移至 Logto）
> **访问方式**: 本手册所有地址均可从 Windows 浏览器直接访问
> **一键体检**: citywalk 仓库运行 `make check-stack`（7 入口 + 5 容器 + WSL 服务 + DB 端口转发，全绿才算收尾）

## 一、网关服务（Docker Compose，真源在 E:/Projects/OmniPG/gateway）

| # | 服务 | 地址 | 说明 |
|:--|:--|:--|:--|
| 1 | **APISIX 网关（数据面）** | http://localhost:9080/ | 所有业务 API 流量入口，jwt-auth(ES384) 鉴权/代理/限流；无 token 访问返回 401 属健康信号 |

| 3 | **APISIX Status API** | http://localhost:7085/status | 健康检查端点，返回 `{"status":"ok"}` |

```bash

psql "postgres://app_owner:dev_password_change_me@localhost:5432/app_db"
```

## 六、快速启动（推荐用开机自愈链，手动为兜底）

```bash
# ⓪ 日常重启 Windows 后无需手动操作：
#    计划任务 "OmniPG Stack Autostart"（登录后 30s）自动执行：
#    拉起 WSL 发行版 -> Docker Desktop -> compose up -> 刷新 portproxy
#    （citywalk 仓库 scripts/register-autostart.ps1 注册；Docker Desktop 设置已开 AutoStart）

# 1.（手动兜底）确保 WSL2 基础设施已启动
wsl -d Ubuntu-26.04 -- systemctl start postgresql@18-main pgbouncer etcd redis-server grafana-server

# 2.（手动兜底）刷新端口转发（Windows PowerShell，管理员）
#    citywalk 仓库: scripts/wsl-portproxy.ps1（5432/5433/6432/3080 全覆盖，含端到端验证）
powershell -ExecutionPolicy Bypass -File E:/Projects/citywalk/scripts/wsl-portproxy.ps1

# 3. 启动 Docker 网关栈（真源 E:/Projects/OmniPG/gateway）
cd /e/Projects/OmniPG/gateway && docker compose up -d

# 4. 一键体检（citywalk 仓库，23 项全绿才算收尾）
make check-stack
```

> ⚠️ **logto 容器挂载已改目录挂载**（`./logto-patch:/tmp/logto-patch:ro`）：Docker Desktop 重启后
> WSL 单文件 bind mount 登记失效会导致容器 Exited(127)（2026-09-05 实战），勿改回单文件挂载。

## 七、验证命令

```bash
# 一键体检（推荐，citywalk 仓库）：7 入口 + 5 容器 + WSL 服务 + DB 端口，23 项
make check-stack

# PostgREST
curl -s http://localhost:3100/ | wc -c          # >2000 字符

# APISIX 就绪
curl -sf http://localhost:7085/status            # {"status":"ok"}

# Logto（OIDC 发现 + Core 页面 + Console）
curl -sf http://localhost:3001/oidc/.well-known/openid-configuration   # 200
curl -s http://localhost:3001/unknown-session     # 200
curl -s -o /dev/null -w '%{http_code}' http://localhost:3002/console/get-started  # 200

# Swagger UI
curl -sf http://localhost:8082/                  # 200

# Pigsty WebUI（:80 即 http://localhost/，二者等价）
curl -sf http://localhost/                       # 200
curl -sf http://localhost:8080/                  # 200

# Grafana 代理
curl -sI http://localhost:8080/ui/d/pgsql-overview  # 302
```
