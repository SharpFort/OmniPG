#### 1.1 修订要点（v1.1 新增）

1. **`user_role` → `user_tenants` 更名**：原 `api_v1_public.user_role` 视图（T7 起即 user_tenants 投影）与 `public.user_role` 表（024 用户↔角色分配镜像）同名不同物，API 消费者极易混淆。034 将视图更名 `user_tenants`（列 = 表列：user_id / organization_id / joined_at）。**前端注意**：查询"用户属于哪些租户/组织"用 `user_tenants` 或 `v_user_list.organizations`；查询"用户被分配了哪些 Logto 角色"用 `v_user_roles` / `v_role_users`（仅超管）或 claims（`get_current_user`）。
2. **两套 role_id 语义**：`user_tenants.organization_id`（= 租户 id）与 `iam_role_api/iam_role_menu/v_role_api_detail.role_id`（= Logto 角色 id）**不是同一 id 空间，禁止互 join**；`role` 视图 `id` 同样是角色 id。角色-API 绑定的关联键是 `role_code`（字符串）。
3. **权限前提速查**：`authenticated` 可读 = 全部表名视图 + v_user_list/v_role_list/v_dept_list/v_system_stats/v_system_stats_realtime/v_user_role_detail/v_role_api_detail/v_role_menu_detail/v_audit_log_detail/v_audit_log_timeline/v_dict_list/v_login_log + dict_type/dict_data（034 补齐）；**仅超管** = v_user_roles/v_role_users/login_log 直查（登录日志页走 RPC）。所有视图受 RLS 行级过滤（租户隔离 + 超管豁免）。
4. **`audit_log` 视图是精简投影**（8 列），019 扩展列（log_type/module/action/target_type/target_id/result/ip/user_agent/region/duration_ms）仅经 `search_audit_log` RPC / `v_audit_log_detail` 可得。

### 1.2 RPC（POST /rpc/{name}）

> ✎ v1.2 已逐项对照源码核实并修订（035 迁移）：删除 3 个、重写 6 个、新增权限档位标注。
> **分页策略（035 定稿）**：`GET /{view}` 用 PostgREST 原生分页（`Range` 头 / `limit`、`offset` 参数，`max-rows=1000` 兜底）；`POST /rpc/{name}` 返回单一 JSON payload，PostgREST **无法**对其 Range 分页 → 搜索类 RPC 自带 `p_limit/p_offset`（上限统一 **100**，页面 10-50 条 offset 翻页足够）。
> **权限档位三档（035 统一）**：🟢 无门槛（SECURITY INVOKER + RLS 行级隔离）/ 🔐 权限点（SECURITY DEFINER + `require_permission(code)`，42501）/ 👑 超管（SECURITY DEFINER + `require_super_admin()`）。

**认证 / 用户**

- `ensure_user()` — 登录后 JIT 兜底建档（返回 sub）；**035 起顺带 user_role 分配镜像全量覆盖**（claims roles = Logto 权威快照，替代已删的 rpc_sync_user_roles）— 🟢（DEFINER 但仅本人 claims）
- `get_current_user()` — 当前用户信息（含 roles，来自 JWT claims）
- `get_user_permissions()` — 当前用户 API 权限（casbin_rule 视图）
- `get_user_menu()` — 当前用户菜单树（扁平列表 [{id,parent_id,name,path,meta:{title,icon}}]）
- `get_all_public_configs()` / `get_config(key)` — 公开配置

**系统管理（SECURITY DEFINER + has_permission 门槛）**

- `search_users(p_query,p_status,p_dept_id,p_limit,p_offset)` — 用户分页搜索 — 🟢（INVOKER+RLS）；⚠️ 035：`p_limit` 上限 100
- `search_audit_log(p_query,p_table_name,p_operation,p_limit,p_offset)` — 审计搜索 — 🟢（INVOKER+RLS）；⚠️ 035：上限 100
- `get_audit_log_timeline(p_start_date,p_end_date)` — 审计时间线
- `get_dept_tree(p_tenant_id uuid)` — 部门树（扁平 + level/path）
- `get_menu_tree_admin()` — 完整菜单树（扁平 + level/sort_order）
- `get_role_permissions(p_role_code text)` — 角色权限详情（apis/menus）
- `update_config(key,value)` — 🔐 `sys:config:write`
- `rpc_search_login_logs(...)` — 登录日志查询 — 🔐 `sys:login-log:list`（030 seed，**仅超管绑定**——租户管理员 42501，前端降级提示）；⚠️ 035：上限 100
- `rpc_list_tenants(p_query,p_limit,p_offset)` — 租户列表 — 🔐 `sys:tenant:list`（**035 补绑 tenant_admin**）；⚠️ 上限 100
