2. **后端地址**：开发机通过局域网访问宿主：`VITE_API_BASE=http://<宿主IP>:3100`；Logto：`VITE_LOGTO_ENDPOINT=http://<宿主IP>:3001`（或实际端口）
3. **Logto Console 调整（关键）**：SPA 应用的 redirect URI / post sign-out URI / **CORS 允许来源**都要加入开发机地址（`http://<开发机IP>:5173`）——否则授权回调被拒
4. **测试账号**：testC / tenant_admin 密码由后端提供；新注册账号走 A-4 流程
5. **每阶段结束**：提交 + 在阶段验收表打勾；遇到后端疑问对照 §1.2 权威清单或审查文档 27~32 号
