## 三、component 链路事实链（M-1 关键查证）

1. 011 种子：iam_menu.component 全空（022 加列时无值）
2. **033 已回填**：`UPDATE iam_menu SET component = regexp_replace(path, '^/', '') || '/index' WHERE menu_type='menu' AND component IS NULL`（如 /system/user → `system/user/index`）
3. 但 `get_user_menu` 的 SELECT 列**无 component**（035 §11 之前）→ 前端拿不到已回填值，只能靠 11 项硬编码映射表
4. 后果：菜单管理页新增菜单 → 配置 path → 前端必须改代码才生效

**修复**：035 补丁给 get_user_menu 加 component 列（menu_cte + 最终 SELECT）；前端映射表保留为兜底（component 为空时用）。前端零改动支持新菜单。
