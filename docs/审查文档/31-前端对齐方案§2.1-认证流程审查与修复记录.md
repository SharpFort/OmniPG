## 二、关键事实链（官方文档核实）

### F-1 忘记密码（end-user-flows/reset-password 官方文档）
1. **配置前置**：Email/SMS connector + Console > Sign-in and account 启用 **Password** 登录方式 + **Forgot password** 验证方式（email/phone 验证码）
2. **效果**：登录页自动显示 "Forgot password" 链接 → 托管流程：输邮箱/手机 → 验证码 → 新密码 → 回登录页
3. **前端零代码**；未配置 connector 时链接不显示，无需前端兜底
4. 登录后改密（可选）：Account API 或 Logto 托管账号设置；`hasPassword` 布尔可注入 custom token claims（本项目不需要——密码全托管）

### F-2 signIn 签名（@logto/vue 3.0.13 npm 实包）
```
signIn: (redirectUri: string | URL, interactionMode?: InteractionMode, loginHint?: string) => Promise<void>
signOut: (postLogoutRedirectUri?: string) => Promise<Optional<void>>
useHandleSignInCallback: (callback?: () => void) => { isLoading: ... }
```
- 第二参数 = `InteractionMode` 字符串枚举（'signIn' | 'signUp'）——**非对象**
- 文档原稿 `{ interactionMode: 'signUp' }` 会导致 TypeScript 类型错误

### F-7 密码策略（官方 security/password-policy + blog NIST 研究）
- 配置位置：**Console > Security > Password policy**
- 最小长度 8（NIST ≥8，长度优先于复杂度）；最小字符类型 1/4（不强制组合——Facebook/Discord/Stripe 实践）；HIBP 泄露密码检查；重复字符检查；用户信息检查；自定义禁用词
- **不强制定期改密**（NIST：仅泄露证据时强制）；登录限速/锁定 + 改密后清其他设备会话 = Logto 内置
- 策略对新密码生效；存量密码可用 `check-password` API 审计（可选）
